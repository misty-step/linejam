## Improvements

- Private poem downloads and social previews are working again, so saved poems and shared links render as expected.
- The game now runs on a faster, self-contained backend, which should make joining and playing feel more responsive.
- Guest sessions are handled more reliably, reducing the chance of connection hiccups when you play without an account.
- Background upkeep for poem sweeps and game recovery is monitored more closely, helping keep games tidy and recoverable.

## Bug Fixes

- Fixed an issue where some poem images failed to download or preview correctly.
- Fixed a problem that could mix up guest session data during busy moments.
- Fixed a rare failure where the game could briefly check a stale version after an update.
- Fixed error tracking so different problems are no longer lumped together, making it easier to spot and fix real issues quickly.
