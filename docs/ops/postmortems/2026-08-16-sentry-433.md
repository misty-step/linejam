## Detection behavior

The expected Sentry integration detected and routed an error classified as `productionSmoke` with failure code `unexpected_error` to the canonical incident Issue. The event is intentionally rebuilt from a closed vocabulary and does not contain the underlying Playwright failure. The available sanitized metadata therefore proves alert emission, not which guest, authenticated, join, or game-start assertion failed.

Repository policy declares that the second consecutive production-smoke failure should open the monitor incident. The checked-in streak function returns a count of one after a prior success and two only after a prior failure. Local execution against the public conclusions for the affected release returned one for a hypothetical next failure. This does not explain the received alert.
